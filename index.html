Method

  1. Find my IP and network rangeip a
  2. Scan my own machine as a baselinenmap 10.0.2.15
  3. Run a TCP SYN scan of the subnetsudo nmap -sS 10.0.2.0/24
  4. Add service and version detectionsudo nmap -sS -sV 10.0.2.0/24
  5. Record hosts, ports and services, then research the risksSee Results and Risks below.
  6. Save the output for the repositorysudo nmap -sS -sV 10.0.2.0/24 -oN scan_results.txt -oX scan_results.xml

Assessment

  • The Windows host exposes three Windows services. SMB and RPC should never be reachable from untrusted segments.
  • Most ports were filtered, which suggests a firewall is dropping unsolicited traffic.
  • The Kali VM exposed no open ports, so its attack surface is minimal.

Recommended hardening

  • Block 135 and 445 at the firewall unless required; restrict to trusted IPs.
  • Disable SMBv1 and patch Windows.
  • Turn off unneeded discovery services (SSDP, WSD).
  • Limit DNS to internal clients and update Unbound.
  • Re-scan regularly for unexpected ports.

Practical takeaways

  • SYN scans need root. -sS uses raw packets, so it needed sudo.
  • Filtered ports slow scans down. They give no reply, so Nmap waits and retries. My scans took 3–4 minutes.
  • Filtered is not closed. A firewall is silently dropping packets, so Nmap cannot say whether a service sits behind it.
  • -sV adds real detail. It turned a plain http on 5357 into Microsoft HTTPAPI httpd 2.0 and named the DNS server as Unbound.
  • Scanning from another host can differ from scanning a machine from itself.
  • Scan only with permission. Unauthorised scanning can be illegal.

Interview questions

What is an open port?

A port where a service is listening and accepting connections, for example 445 for SMB.

How does Nmap perform a TCP SYN scan?

It sends a SYN. A SYN/ACK means open, and Nmap replies with RST instead of finishing the handshake, which is why it is called half-open. A RST means closed. No reply means filtered.

What risks are associated with open ports?

Each one is an entry point: vulnerable or misconfigured services, brute-force attacks, information leakage and lateral movement.

What is the difference between TCP and UDP scanning?

TCP gives clear handshake responses, so scans are fast and reliable. UDP is connectionless: open ports often stay silent (open|filtered) and closed ports return ICMP unreachable, so scans are slow and less certain.

How can open ports be secured?

Close unused services, use firewalls, patch software, enforce strong authentication and encryption, segment the network and monitor with IDS/IPS.

What is a firewall’s role regarding ports?

It allows or blocks traffic by rule (IP, port, protocol) so only required services are exposed.

What is a port scan and why do attackers perform it?

It probes a host for open ports and services. Attackers use it to map targets and find vulnerable services before attacking.

How does Wireshark complement port scanning?

Nmap reports port states. Wireshark shows the actual packets (SYN, SYN/ACK, RST), so you can verify how the scan works and spot scans on your own network.
